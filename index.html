How it works: all people share N base sprites pre-tinted with M shirt hues (so the GPU/2D context only deals with N×M cached canvases). Each person's walk is procedural: bob, sway, leg swing, squash, lean. No spritesheet, no skeleton, no shaders required for this Canvas2D demo — yet the same trick ports 1:1 to a WebGL instanced quad with vertex-shader deformation for the real game.
